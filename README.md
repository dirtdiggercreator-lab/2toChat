# 2chat

Приватный чат на двоих. E2E-шифрование (AES-256-GCM), без регистрации и бэкенда.
Хостится на GitHub Pages, сигналинг — публичный PeerJS, сообщения идут P2P по WebRTC.

## Как работает

1. «Создать чат» → генерируется 32-байтный секрет, попадает в `#hash` ссылки.
2. Из секрета: `roomId = SHA-256("room:"+secret)` (публичный), `key = HKDF(secret, salt=roomId)` (приватный).
3. Первый открывший — host, второй — гость. Если host уходит, гость занимает его место.
4. Сообщения шифруются на клиенте, PeerJS видит только шифротекст.

## Что НЕ защищено

- Метаданные (IP, время, размер) видны PeerJS-серверу.
- Ссылку передавай по защищённому каналу.
- Истории нет: закрыл вкладку — сообщения исчезли.
