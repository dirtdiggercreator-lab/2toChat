# 2chat

Приватный чат на двоих. E2E-шифрование (AES-256-GCM), без сигнального сервера.
Соединение устанавливается вручную обменом кодами через любой мессенджер.

## Как работает

1. Создатель жмёт «Создать чат» → получает ссылку-приглашение и свой код.
2. Отправляет их собеседнику.
3. Собеседник открывает ссылку, вставляет код, генерирует ответ, отправляет обратно.
4. Создатель вставляет ответ → чат открыт.

Секрет чата лежит в `#hash` ссылки и никогда не уходит в сеть.
Из него: `roomId = SHA-256("room:"+secret)`, `key = HKDF(secret, salt=roomId)`.

## Что НЕ защищено

- Сами коды и ссылку нужно передавать по защищённому каналу.
- Без TURN-сервера соединение может не установиться в некоторых мобильных сетях (симметричный NAT).
- Истории нет: закрыл вкладку — сообщения исчезли.

## 6. ЛИМИТЫ CLOUDFLARE (СКОЛЬКО ПОТЯНЕТ КОМНАТ)
- На бесплатном тарифе ограничений по количеству комнат нет. Лимиты считаются по общему трафику:
- Запросы: 100 000 в день (входящие сообщения WebSocket считаются с коэффициентом 20:1, т.е. 100 сообщений = 5 запросов).
- Время работы (Duration): 13 000 ГБ-с в день (расходуется, пока комната активна).
- Хранилище: 5 ГБ (если сохранять историю или файлы на сервере).
- Итог: Для пары человек лимитов хватит с огромным запасом, можно создать сотни комнат.
- Если чат станет популярным, переход на Workers Paid ($5/мес) поднимет лимиты в разы.
